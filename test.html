01 / STRUCTURE

HTML gives content its shape.

HTML stands for HyperText Markup Language. It uses elements (tags) to describe what each piece of content is.

<h1><p><a><img>

Think of HTML as the blueprint

Use headings for hierarchy, paragraphs for text, lists for collections, and anchor tags for navigation. Semantic elements such as <main> and <nav> help browsers and assistive technology understand the page.

index.html
<main>
  <h1>Hello, web!</h1>
  <p>My first page is taking shape.</p>
  <a href="#css">Jump to CSS</a>
</main>
02 / STYLE

CSS brings the personality.

CSS stands for Cascading Style Sheets. It controls how elements look and how they arrange themselves across screen sizes.

colorflexboxgrid:hover

Style with rules

A CSS rule selects an element, then applies declarations. Start with readable contrast, consistent spacing, and layouts that adapt to mobile screens.

styles.css
/* A bold, responsive card */
.card {
  background: #121a2e;
  color: #f4f7ff;
  padding: 1.5rem;
  border-radius: 16px;
}
.card:hover {
  transform: translateY(-4px);
}
03 / INTERACTION

JavaScript makes it respond.

JavaScript runs in the browser and can react to events, change page content, validate input, and communicate with APIs.

eventsDOMfunctions

From static to interactive

JavaScript can listen for a click and update an element without reloading the whole page. Try the demo below to see a simple event handler in action.

script.js
const button = document.querySelector("#hello-button");
button.addEventListener("click", () => {
  document.querySelector("#demo-message")
    .textContent = "Nice! JavaScript is working.";
});
Interactive playground

Press the button and watch the message change.

Your code is ready when you are.

04 / SERVER

PHP works behind the scenes.

PHP is a server-side scripting language. A server runs the PHP code and can return generated HTML to the browser.

server-sideformssessions

Browser vs. server

HTML, CSS, and JavaScript are commonly delivered to the browser. PHP runs on a configured server, where it can process requests and work with databases. A PHP file won't execute just by opening it directly as a local file — use a PHP-enabled server.

hello.php
<?php
$name = "Developer";
$message = "Welcome, " . $name . "!";
echo "<h1>" . htmlspecialchars($message) . "</h1>";
?>

Quick setup note

To test PHP locally, install PHP or use a local development stack, then run a development server from your project folder with php -S localhost:8000.
